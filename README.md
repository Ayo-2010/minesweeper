# Minesweeper

A classic 9 by 9 minesweeper board with ten mines, flags and a timer.

## Features

- First click is always safe, including its neighbouring cells
- Flood reveal for empty cells
- Right click to flag and unflag a cell
- Mine counter and a timer that starts on the first reveal
- Win and loss states with the whole board revealed

## Running it

Open `index.html` in a browser. There is no build step and no dependencies to install.

## Files

```
index.html   markup
styles.css   styling
script.js    behaviour
```

## Tech

Plain HTML, CSS and JavaScript.
